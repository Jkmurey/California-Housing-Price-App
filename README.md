# 🏠 House Price Prediction Web App

## 📌 Overview
This project demonstrates the deployment of a machine learning model using Streamlit.  
The application allows users to input housing features and receive real-time house price predictions.

---

## 🚀 Live Demo
🔗 https://california-housing-price-app-5kmqc3uucuaea8tw3wem2c.streamlit.app/

---

## 🧠 Project Features
- Interactive user interface for inputting housing data
- Real-time predictions using a trained machine learning model
- Integration of a saved `.pkl` model into a web application
- Deployed online using Streamlit Cloud

---

## 🛠️ Technologies Used
- Python
- Streamlit
- Scikit-learn
- Pandas
- NumPy

---

## 📊 Model Details
- Model Type: Linear Regression (or specify your model)
- Dataset: California Housing Dataset

  - R² Score: 0.72
